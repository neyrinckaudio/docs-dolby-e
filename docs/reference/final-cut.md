# Final Cut

SoundCode For Dolby E version 2.0 integrates with Final Cut Pro and Final Cut Express workflows.

## Encoding

The Dolby E encoder operates as an **export plug-in**. Select one or more sequences and choose **SoundCode Dolby E** from the Export menu. The encoder exports a stereo WAV file. If you need to bring the Dolby E stream into a Final Cut project, just import the WAV file.

See [How to encode / export a file in Final Cut](../encode-export/overview.md#how-to-encode-export-a-file-in-final-cut) for the step-by-step procedure and the [Controls Reference](../encode-export/controls.md#additional-controls-in-final-cut) for the Final Cut-specific controls.

## Monitoring

You can monitor a Dolby E stream in Final Cut by using the **N-Mon** utility, which uses the Audio Unit Dolby E decoder:

1. Open the **Audio/Video Settings** dialog.
2. Set **Audio Playback** to **N-Mon**.

See the N-Mon Help system for more information on using N-Mon.
