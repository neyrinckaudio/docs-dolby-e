# Authorization

SoundCode For Dolby E requires an authorized **iLok USB Key** connected to your computer, or a **license file** installed on the computer.

## iLok

An iLok authorization needs to be obtained online and downloaded onto your iLok USB Key.

If you purchased a boxed version, the Activation Postcard included in your purchase contains your **Activation Code** and instructions on how to obtain your plug-in license online. You will need an iLok.com account to complete the process. If you do not yet have an account, visit [www.ilok.com](https://www.ilok.com) to set one up for free.

!!! note "iLok USB Smart Key not included"
    The iLok USB Smart Key is not supplied with your plug-in or software option. You can use the one included with certain Pro Tools systems (such as Pro Tools&nbsp;|&nbsp;HD-series systems), or purchase one separately.

## License file

If you choose to use a license file, you must send a **license request file** to Neyrinck.

To generate the license request file, follow the instructions in the PACE dialog presented when you use SoundCode. Send the license request file to [support@neyrinck.com](mailto:support@neyrinck.com).
