# Installation

Installers can be downloaded from the [Neyrinck website](https://www.neyrinck.com), or found on the plug-in installer CD-ROM included with boxed versions of plug-ins.

## To install SoundCode For Dolby E

1. If Pro Tools is running, **quit** it.
2. Locate and open (double-click) the plug-in installer.
3. Follow the instructions presented by the installation software.
4. When installation is complete, click **Quit**.

When you launch Pro Tools or the standalone application, you will be prompted to [authorize](authorization.md) your new software.

## Removing expired software

If you let a demo version of the plug-in software expire, you should remove it from your system. Otherwise, each time you open your workstation software you will be prompted with a message that the plug-in has expired.

To remove an expired plug-in, open the Plug-Ins folder on your startup drive and drag the expired plug-in to the Trash:

=== "macOS"
    ```
    /Library/Application Support/Digidesign
    ```

=== "Windows"
    ```
    C:\Program Files\Common\Digidesign\DAE\PlugIns
    ```
